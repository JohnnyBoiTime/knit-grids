# knit-tracker

A way for you to keep track of your knitting progress! I got this idea from when i was knitting my friend a scarf and how i kept track was a grid to keep track of the row I was on, as well as which stitch. It was a lot of paper and a lot of writing and my hand hurt, but thanks to the paper i was able to keep track really well and never lost my place when i came back to it. So i thought i'd turn this idea into a web app where you can do just that!
